ボタンで操作する（GitHub の連携）
各タスクのボタン（担当する・Claude に頼む・終わった など）は、GitHub の Issue にコマンドのコメントを書き込みます。数十秒でボットが状態を変えます。
  • 連携なし：ボタンを押すとコマンドをコピーして Issue を開くので、いちばん下のコメント欄に貼って「Comment」を押す。
  • 連携あり：ボタンだけで書き込む。下の手順でトークンを作って貼る（このブラウザにだけ保存されます）。
hknroms（gradius3 の持ち主）
  1. GitHub のトークン作成画面を開く（Fine-grained token）。名前は前と重ならないものに（例：g3-status）
  2. Repository access →「Only select repositories」→ gradius3
  3. Permissions →「Add permissions」→「Issues」→ Read and write
  4. 「Generate token」→ 出てきた文字列（github_pat_…）をコピーして下に貼る（画面の切り替わりが遅いことがあります）
共同管理者（ほかのアカウント）
  1. GitHub のトークン作成画面（classic）を開く
  2. 「public_repo」にチェックが入っていることを確かめる（ほかは要りません）。Expiration（有効期限）を選ぶ
  3. 「Generate token」→ 出てきた文字列（ghp_…）をコピーして下に貼る
  4. 「完了にする」「差し戻す」を使うには、そのアカウントが gradius3 の共同編集者（招待済み）である必要があります。でなければ「自分がやる」「終わった」などだけ使えます
トークンは人に教えず、1人1つずつ作ってください（書いたコメントは、トークンを作った人の名前で残ります）。この画面でしか見られないので、自分用にメモしておくと、別のブラウザでも貼れます。

このページの見方
  • GitHub の Issue のうち、作業の種類（検証・調査・実装・素材・資料）のラベルが付いたものを一覧にしています。開くたびに最新を読み込みます。
  • 新着タブには、まだ種類が決まっていない Issue（Google フォームから届いた報告など）が出ます。ボタンで種類を付けると作業タスクになり、その種類のタブに移ります。
  • タブはそれぞれ直接開けます（例：status.html#協力者、status.html#調査）。
  • 担当・進み具合・提出物は、協力者（の Claude）が Issue にコメントするコマンド（/claim /check /submit /done など）で自動的に変わります。各タスクのボタンでも同じコマンドを書き込めます。
  • 担当の印：🤖 Claude は Claude が作業中（または Claude に頼んで待っている）、👤 人 は人が作業中。
  • 状態：未着手 → 担当中 → 確認待ち（提出済み）→ 完了。人の目や判断が要るものは「要人間確認」。
  • バーの色：緑＝OK／赤＝おかしい／黄＝人の目で確認が必要／灰＝まだ
  • 協力者は、Issue での活動とフォークから自動で載ります。紹介文などは docs/collaborators.json で足せます。
