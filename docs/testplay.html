▶ テストプレイのおすすめのやり方
  1. 気づいたことは、その場でメモする。スマホの音声入力を使うと、遊びながら話すだけで記録できて便利です（下の「音声入力のおすすめ」）。
  2. まず無敵で遊んでみる。メニューで INVINCIBLE を ON にすると、最後まで通して見られます。おかしいと思った所は、その場でメモします。
  3. 画面を撮りたいときは、ポーズをかけて写真を撮る。START を約1秒押し続けるとポーズメニューになります。メモには「写真を撮った」と書いておくと、あとでどの写真がどの話か分かります。
  4. 遊び終わったら、メモをそのまま報告に貼り付けて、撮った写真を添付する。文章を整えなくても大丈夫です。いくつもの話が混ざっていたら、「報告の種類」で「いろいろまとめて（音声メモなど）」を選んでください。こちらで1件ずつに分けます。
  5. 問題がなかった区間も、書いてもらえると参考になります。（例：「5面は最後まで問題なし」）
  6. 実機か MAME か（MAME なら版も）を書いてください。報告のフォームに選ぶ欄があります。

メモに残してほしいこと

  • 今何面か、どのあたりか
  • どう始めたか（メニューで選んだ面・エリア、モード）
  • やった操作（無敵にした、ポーズメニューで何を ON にした、など）
  • 位置の数字：ポーズメニューで POS DISP を ON にすると、画面の右上（RANK の下）に X:1CA0 Y:0000 のように出ます。X の値と、Y が 0 でなければ Y の値も書いてください。同じ場面をすぐ再現できます。
  • 何が起きたか、本当はどうなってほしいか

音声入力のおすすめ

ChatGPT のアプリの、文字を打つ欄にあるマイクのボタンがおすすめです。話した内容を、ある程度直して文字にしてくれます。

  1. 最初に、次の文を送っておきます。言い間違いや聞き間違いを直しながら覚えておいて、最後にまとめて出してくれます。
    これからゲームのテストプレイのメモを、音声入力で何回かに分けて送ります。聞き間違い・言い間違い・誤字を、ゲームの話の流れに合わせて直しながら覚えておいてください。途中は「了解」とだけ返事をしてください。最後に「まとめて」と送ったら、それまでのメモを、起きた順に、面・場所・やった操作・起きたことが分かるように、文章で整理して出してください。「写真を撮った」と話した所は、その場所に「（写真）」と書いてください。
  2. マイクのマーク（赤い丸）を押して話します。右端の青い丸（波の形）は「会話モード」（声でやり取りする）なので、押しません。
  3. 話し終わったら、■（止める）を押します。少し待つと文字になります。
  4. 文字になったら、↑（送信）を押します。
  5. 送られました。遊び終わるまで、気づくたびに 2〜4 を繰り返します。
  6. 最後に「まとめて」と送って、出てきた文を報告に貼り付けます。
  • ボタンの形や場所は、アプリの版によって少し違います。
  • スマホのキーボードのマイクでも入力できますが、日本語では正確さが落ちることがあります。
▶ GitHub のアカウントを作る

GitHub の画面は英語です。下に、押すボタンの英語の表示と、日本語の意味を書いています。表示は時期によって少し変わることがあるので、別の表示も書いておきます。

Chrome の自動翻訳は切っておくのがおすすめです（アドレス欄の右の翻訳のマーク →「英語」）。翻訳がかかると、ボタンの文字がこの説明と変わったり、押しても反応が遅く見えたりします。
  1. github.com/signup を開く。
    github.com のトップページからなら、右上の「Sign up」（登録）を押す。
  2. Email（メールアドレス）を入れる。
    確認の数字がこのアドレスに届きます。
  3. Password（パスワード）を入れる。
    15文字以上、または8文字以上で数字と英小文字を両方含むもの。
  4. Username（ユーザー名）を入れる。
    英数字とハイフン（-）だけ。報告するとこの名前が公開されます。本名でなくて大丈夫です。使えない名前だと赤い字で出るので、変えてください。
  5. Your Country/Region（国）が「Japan」になっているか見る。
  6. Email preferences（お知らせのメールを受け取るか）のチェックは、外したままで大丈夫です。
  7. 緑の「Create account」（アカウントを作る）を押す。
    ボタンが「Continue」（続ける）になっていて、1項目ずつ進む画面のこともあります。その場合は、上の 2〜6 を1つ入れるごとに「Continue」を押します。
  8. パズル（「Verify」／「Visual puzzle」）が出たら、指示どおりに答える。
    ロボットでないことの確認です。何問か続くことがあります。
  9. メールに届く「Your GitHub launch code」の8桁（または6桁）の数字を、画面の「Enter code」の欄に入れる。
    届かないときは迷惑メールのフォルダを見るか、「Resend the code」（もう一度送る）を押す。
  10. 「Sign in」（ログイン）の画面になったら、作ったユーザー名（またはメールアドレス）とパスワードでログインする。
  11. アンケート（「How many team members…」「What specific features…」など）や、有料プラン（「Choose your plan」「Free」「Pro」など）の画面が出たら、いちばん下の「Skip personalization」（飛ばす）か「Continue for free」（無料で続ける）を押す。
    お金はかかりません。無料のままで報告できます。
  12. これで完了です。このページに戻って「GitHub のアカウントをお持ちの方はこちら」を押してください。

報告のフォームのボタンも英語です。いちばん上の「Add a title」（題名）に一言で内容を書き、下の欄を埋めて、いちばん下の緑の「Create」（または「Submit new issue」）を押すと送れます。写真は「Paste, drop, or click to add files」の所にドラッグするか、押して選びます。

▶ MAME の準備

おすすめの MAME

  • 最新の MAMEUI（Windows）：動作を確認できています。これをおすすめします。

確認した範囲で動かなかったもの：Windows の最新の本家 MAME ／ スマホの MAME4droid（ふつうのやり方では起動しない）

ROM（zip）の作り方と置き方

  1. 配布ページの「MAME用 zip を作る」で zip を作る（出力するセットは、おすすめの gradius3j のまま）。
  2. zip は解凍せず、ダウンロードしたフォルダーに置いたままにする。
  3. MAMEUI で、そのフォルダーを ROM を探す場所に足す（ROM のフォルダーに移すより、このほうが新しい版に入れ替えやすいです）。
    メニューの「Options」→「Directories」（ディレクトリ）→ 上の欄で「ROMs」を選ぶ →「Insert」（追加）でダウンロードのフォルダーを選ぶ →「OK」。
  4. 一覧を読み直す（F5）と、Gradius III（Japan, version 3）が出ます。ダブルクリックで起動。
新しい版の zip を作ったら、前の zip に上書きしてください。同じ名前のファイルがあると「gradius3j (1).zip」のような名前で保存され、MAME はそれを読みません（前の版のまま動きます）。前の zip を消してから作るか、名前を gradius3j.zip に直してください。

起動したら

  • 「チェックサムが正しくない」のような警告が出ますが、改造した ROM なので正常です。何かキーを押すと始まります。
  • 電源を入れた直後の「RAM ROM CHECK」の下に、版と作った日時の数字が出ます（例：0 4 17 26 10 26 10:12）。報告のときに書いてもらえると、どの版か確実に分かります。
  • クレジットを入れる：5　1P のスタート：1（はじめの設定）

ボタンの割り当て

  • ゲーム中に Tab → 「Input (this Machine)」（この機械の入力）→ 変えたい項目を選んで Enter → 使いたいボタンを押す。
  • PS5 などのコントローラーが反応しないときは、「Input (this Machine)」で割り当て直すか、DS4Windows や Steam の入力の機能を使うと動くことがあります。

「ROM が見つからない」と出たとき

  • zip の名前が gradius3j.zip になっているか（「(1)」などが付いていないか）。
  • その zip のあるフォルダーが、上の「Directories」の ROMs に入っているか。
  • MAMEUI で選んだのが「Gradius III (Japan, version 3)」か。別のセット（gradius3）で作った場合は「World, version R」を選びます。
