▶ How to use (in game): menu, equipment commands, pause menu, Cube Rush

Entering the hidden menu

  • Insert a credit, then press START while holding the joystick. Pressing START without the joystick starts the game exactly like the original.
    Up + START: menu with default settings
    Down + START: menu with your previous settings
  • To enter the menu, enter the unlock command first (from v0.5.2). When not in a game (during the demo or title screens): Up + A → release both → Down + A → release both (each step within 3 seconds). A sound plays when it is unlocked. If nobody plays for about 120 seconds after unlocking, it locks automatically (there is no lock command). While locked, pressing START with the lever held starts the game as in the original.

Menu

  • Choose an item with Up/Down, change its value with Left/Right, and press START to begin (the menu does not return to the demo). After starting, you go to the type select (Beginner cannot be chosen) and the weapon select screens.
  • Items: INVINCIBLE / MODE (NORMAL, CUBE RUSH) / LOOP / stage and area table / CUBE HEIGHT, SHIFT, TYPE (the Cube Rush sequence; selectable only in Cube Rush) / SHIELD COLOR (shield color) / HUNTER NEXT (type of the first Option Hunter to appear) / FULL POWER SPEED (speed set by the power-up command) / FULL POWER CAPSULE (power-up gauge position after the power-up command).
  • Stage and area table: choose an area with Left/Right. Letters (A, B, …) are the starts of the original areas. Stage 10 ❶ (circled number) is where you head down after the boss rush. The BOSS RUSH row starts partway through the boss rush section of stage 10 (A–E = before the 2nd–6th boss; if you die there you restart from that point). EX STAGE is A = Gradius stage, B = Salamander stage.

Power-up command during play (tap START)

  • Missile, Laser, 4 Options, Shield
    Double instead of Laser
    Full power-up with the normal shot (no Laser or Double)
    Missile, 2 Options
    S = Shot, M = Missile. Hold the highlighted buttons and tap START.
  • Speed always becomes the menu SPEED (lowered if you are faster), and the power-up gauge moves to the menu CAPSULE position.
  • When started from the menu, Stage 1 area A of the first loop starts as in the original; any other stage or area starts with the power-up gauge on SPEED UP (speed stays at the start value; Cube Rush too).
  • After using the power-up command, the first Option Hunter does not appear (it does not count as having appeared either, so the next one is the type chosen in HUNTER NEXT).
  • In NORMAL it can be used once per game; in Cube Rush and while invincible it can be used any number of times. Power-ups are only added, so if you already have Laser or Double you do not go back to the normal shot.

Pause menu (hold START for about 1 second)

  • Hold START for about 1 second to open the pause menu
  • Choose with Up/Down, toggle ON/OFF items with Left/Right or Shot, and resume with START (or Shot). The game timer also stops while paused, so the cube sequence does not drift.
  • CONTINUE (resume) / GAME OVER (quit) / INVINCIBLE / RANK DISP (show the rank) / STAGE DISP (show the loop-stage, area and speed in the 2P score area, e.g. 01-03H SP2 = loop 1, stage 3, area H, speed 2; the area is the original area letter, and when starting from an added numbered point it shows the letter before it; while ON, remaining lives are shown as a number) / POS DISP (show the screen position X/Y below RANK; X:1CA0 means position 0x1ca000) / HIT DISP (show hitboxes; outside Cube Rush) / CUBE INFO (show the Cube Rush sequence and drift, in the high score and 2P areas) / CUBE COLOR (color incoming cubes by the position where they react) / CUBE LINE V (a vertical line in the same color at the position where each cube reacts; Left/Right cycles OFF, ROUGH = coarse dots, FINE = fine dots, EDGE = marks at the top and bottom edges only) / CUBE LINE H (horizontal lines for the 12 possible heights; OFF, ROUGH = coarse dots, LINE = faint line, EDGE = marks at the left and right edges only) / CUBE FLASH (a cube blinks white shortly before it reacts; OFF, SHORT, NORMAL, LONG) / CUBE SE (a sound effect at the moment a cube reacts; OFF or choose a sound; SE 0E = the cursor sound of the weapon select screen) / CUBE HUNTER (ON = only the first Option Hunter appears per Cube Rush run / OFF = none appear; starts OFF). CUBE INFO, CUBE COLOR, CUBE FLASH, CUBE SE, CUBE LINE and CUBE HUNTER appear only in Cube Rush. RANK DISP, STAGE DISP, POS DISP, HIT DISP, CUBE INFO, CUBE COLOR, CUBE FLASH, CUBE SE, CUBE LINE and CUBE HUNTER return to OFF each time you start from the menu.

Cube Rush

  • Lives are the DIP switch setting + 4. Each cube that sticks gives 1000 points (this does not affect the high score, rankings or extra lives).
  • The power-up gauge is fixed on SPEED UP (it stays on SPEED UP after use; up to speed 5).
  • When the cube section ends and the screen has stopped for about 2 seconds, instead of going on to the stage 9 boss you lose one life (without the explosion) and restart from the beginning of the Cube Rush (lives are lost even while invincible). The game is over when you run out of lives.

Build a zip for MAME

  1. Drop all of your genuine ROMs here at once (a zip, a zip inside a zip, or loose files are all fine).
    You need: the full gradius3 set for MAME (version R) and the two version 313 main ROMs (945_313.f15 / 945_312.e15). Files are identified by their contents (CRC), not their names.
  2. When everything is ready, press "Build zip" to download a zip you can put straight into MAME's roms folder.
    You can choose the output set: gradius3j (on newer MAME such as 0.289 it runs as "Japan, version 3, newer" = version 313; recommended), gradius3 (runs as "World, version R"), or gradius3j for older MAME ("Japan, program code S"). The modded ROMs inside are the same in every case; only the file names differ.
ROMs are processed only inside your browser and are never sent anywhere. Keep a copy of your original gradius3.zip / gradius3j.zip somewhere else so it does not get overwritten. MAME will warn about a checksum mismatch, but the game runs.
