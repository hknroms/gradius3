# 文字（字の番号）の使われ方（#97、2026-11-01）

`chs.lua`：メニューから ST 面を無敵で始め、END フレーム（既定 12000）の間、文字の面3枚（固定・A・B）が参照する字の番号と、
字の絵（0xC00〜0xFFF）が 0 以外になった字を記録する。`ST=3 OUTLOG=l.txt G3=$HOME/g3/g3 bash src/lua/run.sh <romdir> chs.lua <out>`

結果：**3面は 0xC00〜0xFFF をほぼ全部使う**（始めて約340フレームから地形の面が順に参照し、約3000〜9000フレームで絵が入る）。
HIT DISP が借りている 0xE80〜0xE86 も3面で使われる → 3面で HIT DISP を ON にすると、地形の字に印の絵が出る・地形の当たりが変わるおそれ（v0.5.1 から）。
1〜10面のどこでも参照されない字は 160個（ほとんどがフォントの使わない字 0x0A〜0x0F・0x2A〜0x3E・0x58〜0x63・0x74〜0x7F・0x8B〜0xAF など。絵は入っている）。
