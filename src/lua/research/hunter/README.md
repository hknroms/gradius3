# オプションハンターの時間の数え方（#93 の後半、2026-11-01）

`hcnt.lua`：メニューから ST 面（RI=1 で A）を無敵で始め、すぐ装備コマンド（オプション4つ）を使い、
ハンターの時間が減るフレーム（`$42E53`=0 かつ 2周目以降か `$42E5B`≥3）を数える。`$42E53` が変わるたびに記録し、
4000フレーム以上ボス戦が続いたら（無敵のままでは倒せない）止める。
`ST=5 OUTLOG=l.txt G3=$HOME/g3/g3 bash src/lua/run.sh <romdir> src/lua/research/hunter/hcnt.lua <out>`（9面は `XEND=58000` でキューブラッシュの開始位置まで）

結果（v0.5.3 の作業中のビルド）：面の始めから最初のボス（中ボス）まで数えたフレーム
5面 8823（中ボス x=$D20C0）／6面 9543（ボス x=$A9080）／7面 4458（x=$630C0）／8面 6763（x=$97020）／9面 開始〜キューブラッシュの開始位置（x=$58000）5471。
オプション4つなら1回 16384 フレームで次のハンター。中ボスの後・ボスの後・面の切り替えの間は、ボスを倒せないので測れていない。
