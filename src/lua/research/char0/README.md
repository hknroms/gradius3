# 数字の「0」が化ける（#90、2026-10-31）

`tap.lua`：サブの字の0番の絵（`$280000〜$28001F`）への書き込みを、書いた PC ごとに記録する（500フレームごとに中身の変化も見る）。

```bash
OLOG=r.log NEXT0=$L/g3run.lua HOLDK="<解除>,1495:U:20,1500:START:5" SEQ="1400:COIN,1730:START" POKE="1700:103f0b:4,1700:103f20:1" END=45000 bash $L/run.sh <ROM>/mame $L/research/char0/tap.lua x
```
（MODE は v0.5.2 なら 2、#35 の後は 4 が CUBE RUSH。無敵でキューブラッシュを続ける）

結果：v0.5.2 で、表示の ON/OFF に関係なく、f15498・f31424 に純正のサブ `$7F30`（`$7DAE` のくっついたキューブの絵を地形の字に描くループの中）が字の0番に書いた。
その升目の字が 0 番（専用の字が用意されていない）だったため。直した後は、同じ所で描くのを飛ばした（`StickPix`、約3万フレームの所で144ドット）。字の0番は変わらない。
