# 面の途中から始めたときの間違った「面クリア」（#64・alamone さんの申し出②）

改造ROMでメニューから各面・各エリアで始め、面の出来事（`$40082` への書き込み）と状態（`$40029`）を記録する。
`$40082` の bit6（`$40`）が書かれる、または状態7（面クリア）に入れば、間違った面クリア。

```bash
L=<リポジトリ>/src/lua
# 無敵・600フレーム（開始の1フレーム目にまとめて出来事が実行されるのを見る）
OLOG=s5_5.log NEXT0=$L/g3run.lua SEQ="1400:COIN,1730:START,1870:B1,1950:B1,2030:B1" HOLDK="1495:U:20,1500:START:5" POKE="1700:103f08:5,1700:103f0a:5,1700:103f20:1" END=9000 bash $L/run.sh <改造>/mame $L/research/clrgate/gate.lua x
# やられて再開も見る: 無敵なし・PLAY=4000
```
結果（2026-10-31・v0.5.2 準備のビルド）：1〜10面・EX の全50エリアで、開始・やられた後の再開（各3〜4回）とも、`$40` は一度も書かれず、状態7にもならなかった。
